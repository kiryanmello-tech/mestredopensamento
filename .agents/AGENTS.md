# Diretrizes do Projeto: Mestre dos Pensadores

Estas regras foram criadas pelo usuário e devem ser rigorosamente seguidas em todas as interações e decisões de desenvolvimento deste projeto:

1. **Pesquisar antes de presumir**:
   - Toda vez que for presumir algo sobre o ambiente, funcionamento de bibliotecas, APIs, fuso horário ou infraestrutura, realize uma pesquisa ou teste de validação prévio para ter certeza antes de agir. Nunca assuma premissas às cegas.

2. **Prevenir erros proativamente**:
   - Andar sempre na frente no desenvolvimento, prevendo possíveis erros de concorrência, limites de cota, restrições do sistema operacional e compatibilidade de layouts antes que eles aconteçam, blindando o projeto contra falhas.
